Описание тестов и файлов.
Добавлены фикстуры в файл conftest.py. 
Фикстуры позволяют избавиться от повторяющихся кусков кода, не относящихся непосредственно к тесту.
Открытие и закрытие драйвера происходит в одной фикстуре run_driver.
Реализована возможность передачи ссылки на нужную страницу сайта в фикстуру run_driver, чтобы одну фикстуру можно было использовать универсально.

Во всех тестах добавлено неявное ожидание driver.implicitly_wait(10) в 10 секунд, т.к не знаю как быстро загрузятся элементы на странице.

Локаторы находятся в файле locators.py.
Локаторы реализованы на основе XPath через //tag[@attribute='value'] либо //tag:[text()='Value']
Для полей Имя, Пароль и Email была вынуждена использовать конструкцию типа /following::input[1], так как на сайте все три поля не имеют уникальных аттрибутов

I. Для регистрации (файл test_registration_page.py):
1) test_successful_registration() - успешная регистрация.
2) test_registration_error_for_invalid_password() - для ошибки некорректного пароля. 

II. Для авторизации (файл test_authorization.py):
1) test_login_button() - вход по кнопке "Войти в аккаунт".
2) test_personal_account_button() - вход через кнопку "Личный кабинет".
3) test_registration_button() - вход через кнопку в форме регистрации.
4) test_password_recovery_button() - вход через кнопку "Восстановление пароля".

III. Для перехода в личный кабинет (файл test_personal_account_access.py):
Локаторы не добавлялись, т.к тест один и проверка насколько я поняла именно самого перехода, ссылки, но не последующей авторизации в него.

test_personal_account_access() - переход по клику на кнопку "Личный кабинет"

IV. Для перехода из личного кабинета в конструктор (файл test_navigation_from_profile.py):
1) test_go_to_constructor() - переход из личного кабинета по клику на "Конструктор".
2) test_go_to_logo() - переход из личного кабинета по клику на логотип Stellar Burgers.

Была добавлена авторизация, т.к личный кабинет доступен только авторизованному пользователю.

V. Для выхода из аккаунта (файл test_logout.py):

test_logout() - выход по кнопке «Выйти» в личном кабинете. 

Была также добавлена авторизация, т.к личный кабинет доступен только авторизованному пользователю.

VI. Для раздела "Конструктор" (test_constructor_navigation.py):
1) test_go_to_bulki() - переход к разделу "Булки". Решила сначала перейти на другой раздел, т.к раздел "Булки" по дефолту отображается при открытии страницы.
2) test_go_to_sauses() - переход к разделу "Соусы".
3) test_go_to_fillings() - переход к разделу "Начинки".
